# IT Network Troubleshooting Assistant

A beginner-friendly Python project that assists with
common IT network troubleshooting tasks.

## Project Objective

The goal of this project is to connect Python programming
with practical IT support and networking scenarios.

## Features

- Check local IP configuration
- Ping an IP address or hostname
- Perform DNS lookup
- Run basic network diagnostics
- Menu-driven command-line interface
- Exception handling
- Cross-platform ping support

## Technologies

- Python 3
- subprocess
- socket
- platform
- Networking fundamentals
- Command-line troubleshooting

## How to Run

Install Python 3.

Open a terminal in the project directory.

Run:

python main.py

On some systems:

python3 main.py

## Example

1. Check IP configuration
2. Test gateway / host with ping
3. Test DNS lookup
4. Run full diagnostics
5. Exit
